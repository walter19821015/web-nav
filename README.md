# Pipilu Web Tools / 网页实用工具大全

> 一个轻量、快速、无广告的在线工具与书签导航平台，基于 Cloudflare 全球边缘网络构建。
> A clean, lightweight, ad-free online utility hub hosted on Cloudflare Pages.

🌐 **线上访问地址 / Live Site**: [https://web-nav.walter19821015.ccwu.cc/](https://web-nav.walter19821015.ccwu.cc/)  
📌 **反馈与工具收录 / Feedback & Requests**: [提交 Issue / Open an Issue](https://github.com/walter19821015/web-nav/issues)

---

## 💡 项目特点 / Key Features

- **⚡ 全球极速分发**：依托 Cloudflare 全球边缘 CDN 节点，秒级响应，毫秒级加载。
- **🛡️ 纯净无广告**：零商业广告、零追踪器、无需注册即可直接使用各类在线工具。
- **🔍 即时搜索**：毫秒级多关键词实时过滤与分类检索。
- **📱 响应式设计**：完美适配 PC、平板与手机端交互体验。
- **💾 数据安全与容灾**：后台配置与书签数据完全独立，支持多版本 JSON 一键导入导出与云端备份。
